# Use layered 2D art instead of true 3D

The Depot will use layered raster illustrations with perspective, soft shadows, and depth to create a 2.5D world. True 3D would add model, camera, lighting, runtime, and asset-consistency work without improving the toddler's cause-and-effect play, while completely flat art would provide less spatial separation between the road, railway, and sky. This choice keeps the first Game lightweight in the browser and lets us create a consistent original asset set with an image-generation model.
